# Personal Portfolio Website

A static personal portfolio website built with HTML, CSS, JavaScript, images, fonts, and front-end vendor libraries. The primary website entry point is located at `index/index.html`.

## Features

- Portfolio-style landing page
- Static sections and navigation
- Visual assets, fonts, and front-end library resources
- Responsive styling and client-side interactions

## Technology

- HTML5
- CSS3 / SCSS assets
- JavaScript
- Local static assets and vendor libraries

## Run locally

1. Clone or download this repository.
2. Open `index/index.html` in a modern browser.
3. Keep the `index/assets/` folder and other referenced assets in their existing relative paths.

No server-side runtime is included for the static portfolio view.

## Customize it

Replace sample text, project descriptions, contact details, and photos with information you are comfortable publishing. Check all links, mobile layouts, accessibility, and asset licenses before deployment.

## Privacy

Do not publish phone numbers, home addresses, private documents, or credentials in a public portfolio.
